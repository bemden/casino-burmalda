# Казино «Бурмалда»

Дон Морковелло начинает расследование пропажи Золотого Жетона — ключа от
главного хранилища. Ему кажется, что жетон украл кто-то из своих, поэтому
улики нужно искать в самом казино. Дон даёт игроку 250 морковок. Победа в каждой из четырёх мини-игр
открывает улику.

## Игры и развитие

- **Слоты** — пара приносит чистую прибыль +50%, тройка одинаковых символов
  даёт шестикратную выплату; магнит может свести символы.
  
- **Блэкджек** — бери карты или остановись до 21; рентген показывает
  следующую карту, которую возьмёт игрок или дилер.
  
- **Скачки кроликов** — выбери кролика по стилю и коэффициенту. С запиской букмекера
  можно узнать двух зайцев, один из которых точно придет к финишу первым.
  
- **Кости** — угадай чётность суммы; правильный ответ возвращает двойную ставку.
  
- **Чёрный рынок** — покупай ограниченные заряды магнита, рентгена следующей
  карты и записки букмекера.

В любой игре можно поставить минимум 50 морковок. На чёрном рынке запас
каждого предмета ограничен тремя штуками за игру.

## Сборка и запуск

Нужны CMake 3.13+ и компилятор с поддержкой C++17.

```bash
cmake -S . -B build
cmake --build build
./build/BurmaldaCasino
```

Для Windows с генератором Visual Studio:

```powershell
cmake -S . -B build
cmake --build build --config Debug
.\build\Debug\BurmaldaCasino.exe
```
