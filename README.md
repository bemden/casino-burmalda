# Казино «Бурмалда»

Дон Морковелло начинает расследование пропажи Золотого Жетона — ключа от
главного хранилища. Ему кажется, что жетон украл кто-то из своих, поэтому
улики нужно искать в самом казино. Дон даёт игроку 250 морковок. Набрав 500,
игрок слышит
оговорку дилера: жетона у Дона нет. Победа в каждой из четырёх мини-игр
открывает улику; отметка после названия мини-игры показывает, найдена ли её
улика (`[✓]` — найдена, `[✗]` — ещё нет).
Собрав все четыре, игрок может выбрать новый пункт и заплатить дилеру 5000
морковок. Только после оплаты дилер признаётся: жетон украл старый друг Дона,
а сам дилер случайно выдал ему место хранения. Жетон находят и возвращают
Дону, после чего появляется финальный экран с салютом.

## Игры и развитие

- **Слоты** — пара приносит чистую прибыль +50%, тройка одинаковых символов
  даёт шестикратную выплату; магнит может свести символы.
- **Блэкджек** — бери карты или остановись до 21; рентген показывает
  следующую карту, которую возьмёт игрок или дилер.
- **Скачки кроликов** — выбери кролика по стилю и коэффициенту, смотри
  анимированный забег и болей за свою ставку. С запиской букмекера бегут
  только два зайца из неё.
- **Кости** — угадай чётность суммы; правильный ответ возвращает двойную ставку.
- **Чёрный рынок** — покупай ограниченные заряды магнита, рентгена следующей
  карты и записки букмекера с двумя кандидатами; только они участвуют в забеге.

В любой игре можно поставить весь текущий баланс. На чёрном рынке запас
каждого предмета ограничен тремя штуками за игру. Когда баланс впервые
опустеет, Мята выдаст 300 морковок и один случайный предмет; этот бонус не
уменьшает запас чёрного рынка.

## Управление

Все меню работают цифрами и Enter. Полный текст диалога показывается сразу;
Enter продолжает сцену. После обнаружения всех улик в меню доступна оплата
дилеру; при недостатке морковок меню подскажет, сколько ещё нужно.
Во время блэкджека нажми `1`, чтобы взять карту, или `0`, чтобы остановиться.
В любом меню `0` обычно возвращает назад или завершает игру.

## Сборка и запуск

Нужны CMake 3.13+ и компилятор с поддержкой C++17.

```bash
cmake -S . -B build
cmake --build build
./build/BurmaldaCasino
```

Для Windows с генератором Visual Studio:

```powershell
cmake -S . -B build
cmake --build build --config Debug
.\build\Debug\BurmaldaCasino.exe
```
